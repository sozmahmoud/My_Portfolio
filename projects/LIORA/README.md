# 🌷 LIORA — Flower E-commerce Website

LIORA is a full PHP and MySQL-based online flower shop project created as a university web development and database project. The website includes a complete shopping experience with product browsing, cart management, user accounts, checkout, reviews, and admin-related features.

---

## ✨ Project Overview

This project was developed to demonstrate a practical e-commerce system with a database-driven backend. It combines front-end web pages with server-side PHP logic and MySQL storage to support real online shopping functionality.

---

## 🌸 Main Features

- Beautiful flower catalog and product pages
- User registration and login system
- Shopping cart and wishlist support
- Checkout and order processing flow
- Product details and search functionality
- Review and rating support
- Special date reminders and user-related features
- Reward points and order management features
- Admin support for managing store data and users

## 🚀 Setup Instructions

This project is not a front-end-only static website. It requires a working PHP and MySQL environment such as XAMPP.

### 1. Install and run a local server
- Start Apache and MySQL in XAMPP
- Place the project in the htdocs folder

### 2. Database setup
- The application will attempt to create and initialize the database automatically
- The database structure is defined in schema.sql
- The setup flow is handled through the included PHP scripts

### 3. Custom database credentials
If your MySQL username, password, or database name is different from the defaults, you can use:
- config.local.php (copy from config.local.php.example)
- Or environment variables:
  - LIORA_DB_HOST
  - LIORA_DB_USER
  - LIORA_DB_PASS
  - LIORA_DB_NAME
