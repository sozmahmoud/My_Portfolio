# COVID-19 Global Data Analysis Project

This project analyzes global COVID-19 trends using Python (Pandas) and SQL Server. It combines data cleaning, transformation, and SQL-based analysis to study cases, deaths, population impact, and vaccination progress across countries and continents.

The project is organized in a simple and practical workflow:

1. Load the raw COVID dataset in Python
2. Clean and transform the data with Pandas
3. Split the raw dataset into deaths and vaccinations tables
4. Load the cleaned data into SQL Server
5. Run SQL queries for analysis and reporting
6. Build charts and summaries from the final SQL results

---

## Project Overview

The purpose of this project is to explore how COVID-19 affected different countries and regions over time. The analysis covers:

- total cases and deaths by country
- death rate per million people
- vaccination progress
- comparisons across continents
- date-based trends
- high-risk countries and regions

This type of analysis is useful for understanding public health patterns, comparing impact across regions, and preparing business or academic reporting based on real-world health data.

## Dataset

- iso_code
- continent
- location
- date
- population
- total_cases
- new_cases
- total_deaths
- new_deaths
- total_vaccinations
- people_vaccinated
- new_vaccinations

The raw file is:

- dataset/owid-covid-data.csv

The notebook and SQL script split this large dataset into two tables for cleaner analysis:

- dataset/CovidDeaths.csv
- dataset/CovidVaccinations.csv

---

## Data Cleaning and Transformation

The Python notebook performs the following tasks:

- reads the raw OWID dataset
- filters rows to the needed time range
- removes unwanted country sub-regions
- keeps large country-level records and summary rows
- ensures dates are in a standard format
- splits the dataset into two structured tables
- saves the final CSV files for SQL import
- generates charts for insights and reporting

### Pandas operations used

- read_csv()
- to_datetime()
- filtering with boolean masks
- groupby()
- nlargest()
- merge and data selection
- fillna()
- sorting and ranking
- exporting CSV files

These steps are important because raw global datasets often contain noisy values, duplicate records, and missing entries that need to be cleaned before analysis.

## Notebook Workflow

The notebook is the main analysis environment. It usually follows this process:

### Step 1: Setup

- define data paths
- verify dataset files exist
- confirm the working folder

### Step 2: Data Preparation

- read the source CSV file
- clean date columns
- filter the time range and relevant entries
- remove unwanted regions like England, Scotland, etc.
- save CSV-ready outputs

### Step 3: SQL Import

- connect to SQL Server using SQLAlchemy and PyODBC
- upload the cleaned tables to the database
- validate successful insertion

### Step 4: Data Querying

- read final SQL tables into Pandas
- combine and summarize records
- perform additional analysis in Python if needed

### Step 5: Visualization

The notebook produces charts such as:

- Top 10 countries by deaths per million
- Vaccination vs deaths
- Top 15 countries by deaths per million
- Timeline of deaths per million by country
- Bubble chart comparing vaccination coverage vs. death rate

These charts are saved as PNG files into the `covid_charts` folder.

## How to Run the Project

### 1. Install Python dependencies

Use Python and install the required packages:

```bash
pip install pandas matplotlib sqlalchemy pyodbc
```

### 2. Make sure SQL Server is available

The project expects a SQL Server database named:

```text
CovidProject
```

Make sure:

- SQL Server is running
- ODBC driver is installed
- the SQL database is accessible

### 3. Open the notebook

Open:

- covid_19.ipynb

Then run the cells in order.

### 4. Run the SQL script

Open:

- covid_19.sql

and execute it in SQL Server Management Studio or Azure Data Studio.

### 5. Generate charts

Once the summary table is available, run the chart cells in the notebook to create PNG files.
