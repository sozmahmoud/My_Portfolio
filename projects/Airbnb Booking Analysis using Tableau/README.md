# Airbnb Booking Analysis

This project is a Tableau-based analysis of Airbnb listing performance and revenue trends. It explores how listing characteristics such as bedroom count, ZIP code, and booking period influence pricing and revenue.

## Project Overview

The dashboard analyzes:

- Average price per bedroom
- Distribution of listings by bedroom count
- Price comparison by ZIP code
- Revenue trends over time
- Geographic/location-based booking patterns

This is designed as a visual business intelligence project for understanding listing performance and pricing structure in an Airbnb dataset.

| File | Description |

## Dataset Summary

The source workbook includes multiple data tables used to build the analysis, including:

- `Listings` – property attributes such as room type, location, price, bedroom count, and other listing details
- `Reviews` – guest review information and related listing activity
- `Calendar` – date-based availability and pricing information

These tables are combined in Tableau to create a time-based and location-based view of the Airbnb business.

## Dashboard Highlights

The workbook focuses on key Airbnb KPIs, including:

- Average price by bedroom count
- Revenue contribution by ZIP code
- Listing count by number of bedrooms
- Price trends across dates
- ZIP code price comparison using charts and map views

## How to Use

1. Open `Airbnb Booking Analysis.twbx` in Tableau Desktop or Tableau Reader.
2. If the workbook asks for a data source refresh, reconnect to the source Excel file if needed.
3. Review the dashboard sheets to interpret pricing, occupancy, and revenue patterns.
4. Use the filters and chart interactions to explore different ZIP codes, bedroom levels, and time periods.

## Requirements

- Tableau Desktop or Tableau Reader
- Microsoft Excel (for the source data file)

## Goal of the Analysis

The goal of this project is to provide a clear visual understanding of:

- which listing types are priced higher,
- which ZIP codes generate more revenue,
- how bedroom count affects price,
- and how prices change over time.

This makes the workbook useful for market analysis, pricing insights, and Airbnb performance storytelling.

## Notes

This project is intended for portfolio or learning demonstration purposes and can be expanded with additional metrics such as occupancy rate, booking conversion, host performance, and neighborhood comparison.
